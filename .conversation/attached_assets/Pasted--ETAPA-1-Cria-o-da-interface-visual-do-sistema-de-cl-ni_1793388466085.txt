# ETAPA 1 — Criação da interface visual do sistema de clínica de estética

Quero iniciar o desenvolvimento de um sistema web profissional de gestão e agendamento para uma clínica de estética.

Nesta primeira etapa, concentre-se exclusivamente na construção do FRONTEND, na identidade visual e na estrutura de navegação. Não implemente ainda integrações com banco de dados, Google Agenda ou WhatsApp.

## 1. Tecnologias
- React
- Vite
- JavaScript
- CSS ou Tailwind CSS
- React Router para navegação
- Lucide React para ícones

Organize o projeto com componentes reutilizáveis e código limpo.

## 2. Identidade visual

O sistema deve transmitir elegância, sofisticação, delicadeza e profissionalismo.

Paleta de cores:
- Rosa principal: #D98FA8
- Rosa claro: #F7E8ED
- Rosa suave: #EBC5D2
- Dourado: #C5A15A
- Dourado claro: #E5D2A3
- Branco: #FFFFFF
- Fundo: #FAF8F7
- Texto principal: #51434A
- Texto secundário: #93838A

Diretrizes:
- Interface minimalista e sofisticada.
- Sidebar lateral elegante.
- Cards com cantos arredondados.
- Sombras suaves.
- Botões em rosa com detalhes dourados.
- Ícones delicados e consistentes.
- Tipografia elegante nos títulos e moderna nos textos.
- Layout responsivo para computador, tablet e celular.

Evite excesso de elementos decorativos e aparência genérica de dashboard.

## 3. Estrutura administrativa

Criar um painel administrativo com menu lateral contendo:

- Dashboard
- Agenda
- Clientes
- Serviços
- Profissionais
- Configurações

### Dashboard
Criar uma tela inicial com:
- Total de atendimentos do dia.
- Atendimentos confirmados.
- Atendimentos pendentes.
- Cancelamentos.
- Próximos atendimentos.
- Resumo semanal.
- Gráficos simples.

### Agenda
Criar uma interface de calendário com:
- Visualização diária.
- Visualização semanal.
- Visualização mensal.
- Horários e compromissos.
- Diferenciação visual dos status.
- Botão para adicionar agendamento.

### Clientes
Criar uma tela com:
- Lista de clientes.
- Campo de pesquisa.
- Botão para cadastrar cliente.
- Informações básicas.
- Acesso ao histórico de atendimentos.

### Serviços
Criar uma tela com:
- Lista de procedimentos.
- Nome.
- Descrição.
- Duração.
- Preço.
- Status.
- Botão para adicionar serviço.

### Profissionais
Criar uma tela para visualizar e cadastrar profissionais.

### Configurações
Criar uma tela com seções para:
- Dados da clínica.
- Horários de funcionamento.
- Integração com Google Agenda.
- Configurações de mensagens.
- Preferências do sistema.

## 4. Página pública de agendamento

Criar uma página independente do painel administrativo, acessível por um link público.

A página deverá apresentar:
- Identidade visual da clínica.
- Apresentação dos serviços.
- Seleção de procedimento.
- Seleção de profissional.
- Seleção de data e horário.
- Formulário com nome, telefone e e-mail.
- Resumo do agendamento.
- Tela de confirmação visual.

Nesta etapa, utilizar dados fictícios de demonstração, claramente identificados.

## 5. Componentes reutilizáveis

Criar componentes para:
- Sidebar.
- Header.
- Cards de indicadores.
- Tabelas.
- Modais.
- Formulários.
- Botões.
- Calendário.
- Badges de status.
- Campos de pesquisa.

## 6. Regras importantes

- Todas as páginas devem possuir navegação funcional.
- Botões e menus devem responder às interações.
- Formulários devem possuir validações visuais.
- Criar estados vazios, carregamentos e mensagens de feedback.
- Não criar integrações simuladas como se fossem reais.
- Utilizar dados de demonstração somente para visualizar as interfaces.

## Resultado esperado

Entregar um frontend completo, consistente, elegante e responsivo, com todas as páginas e navegações estruturadas.

Não avance para integrações ou banco de dados nesta etapa.

Preserve a estrutura do projeto para que possamos implementar o Supabase na próxima fase.
